# Core ceremony key integration

Depends on [Zolana #525](https://github.com/helius-labs/zolana/pull/525) and
[zk-tools #7](https://github.com/helius-labs/zk-tools/pull/7).
The native SDK, example backend and fixture tool use the same reviewed source
revision. Both key manifests and the example's download checksum follow it.
The response fixture was regenerated by proving its existing request with the
final converted key; its proof was not relabeled with a new hash.

All 41 conversions were generated using the SDK's existing zopro revision
`683c0bb3b66c059dd0c0699f44a763cecb309012`, with a real proof verified for each.
The gnark and converted files are published under the immutable CDN prefix
`proving-keys/78751f5d1c591777`. `key-catalog-source.json` authenticates the
upstream conversion manifest; the native loader checks every downloaded file.

The runtime additionally pins the input-flags fix in zk-tools #7: the previous
parser overflowed for transfers with at least 22 inputs. This changes request
validation only; the converter and published key bytes remain unchanged.

This draft updates key pins and fixtures. It does not publish a Flutter package
or update deployed programs. Release it alongside the application verifier and
prover rotation; an old verifier cannot accept proofs from the new keys.

Validation commands:

```sh
python3 scripts/sync-key-catalog.py --check
bash scripts/stage-demo-assets.sh
ZOLANA_TEST_KEYS=packages/zolana_mobile/example/assets/proving cargo test --locked --workspace
ZOLANA_TEST_KEY_DIR=.cache/proving cargo test --locked -p zolana-mobile proves_ -- --ignored
```

Local validation passed: 106 workspace tests and both opt-in proving tests,
including all eight transfer/merge request fixtures. The catalog matches all
41 upstream conversions, and example asset staging passed.

Cluster-dependent wallet flow tests and device/emulator checks are separate
rollout checks. The linked source commit must remain reachable when this draft
is merged; if the application PR is squashed, repin to its merged commit and
rerun catalog and dependency checks.
